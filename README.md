Fenominal: Phenomenal text mining for disease and phenotype concepts 
====================================================================

Rust implementation of the exact-matching algorithm from [fenominal](https://pubmed.ncbi.nlm.nih.gov/38001031/). Fenomimal implements mining of 
[Human Phenotype Ontology (HPO)](https://pubmed.ncbi.nlm.nih.gov/37953324/) or 
[Medical Action Ontology (MAxO)](https://pubmed.ncbi.nlm.nih.gov/37963467/) terms from clinical texts.




## Documentation

A detailed tutorial is available on the [Project Documentation Page](https://p2gx.github.io/fenominal/).
